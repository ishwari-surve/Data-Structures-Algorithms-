## **Queue in Java**

This folder contains programs that demonstrate the fundamental concepts of Queue in Java, including queue operations, implementation using linked lists, and object-oriented programming concepts.

## Topics Covered
### Queue Concept
-FIFO (First In First Out)
-Front
-Rear
-Enqueue operation
-Dequeue operation

### Queue Implementation
-Queue using Array
-Queue using Linked List
-Class and Object
-Dynamic object creation

### Node Structure
-Data member
-Next reference
-Self-referential structure
-Linking nodes together

### Queue Operations
-Enqueue
-Dequeue
-Display
-Count

### Check Empty condition
Queue Analysis
Best Case
Average Case
Worst Case
Time Complexity
Space Complexity

## Node Structure
Node
│
├── data
│
└── next
    │
    ▼
  Next Node

### For a Queue using a singly linked list:
front
  │
  ▼
+------+-------+    +------+-------+    +------+-------+
| data | next  | -> | data | next  | -> | data | NULL  |
+------+-------+    +------+-------+    +------+-------+
                                              ▲
                                              │
                                             rear
