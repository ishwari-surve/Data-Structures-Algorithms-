# Tree in Java

This folder contains programs that demonstrate the fundamental concepts of **Trees in Java**, with a focus on creating, traversing, searching, and manipulating tree-based data structures.

## Topics Covered

1. **Tree Concept**
   - Root node
   - Parent node
   - Child node
   - Leaf node
   - Internal node
   - Subtree
   - Height and depth

2. **Binary Tree**
   - Each node has at most two children
   - Left child
   - Right child
   - Tree structure using nodes

3. **Binary Search Tree (BST)**
   - Inserting elements
   - Searching elements
   - Maintaining sorted order
   - Left subtree contains smaller elements
   - Right subtree contains larger elements

4. **Tree Traversals**
   - Preorder Traversal
   - Inorder Traversal
   - Postorder Traversal

5. **Tree Operations**
   - Create tree
   - Insert node
   - Search node
   - Display tree
   - Count nodes
   - Calculate tree height

## Node Structure

```text
        +---------+
        |  data   |
        +---------+
        |  left   | -----> Left Child
        +---------+
        |  right  | -----> Right Child
        +---------+
```

## Key Learning Points

- Understand the basic concept of a Tree.
- Understand the structure of a Binary Tree.
- Learn how nodes are connected using references.
- Understand the concept of root, parent, child, and leaf nodes.
- Learn how to create and manipulate a Binary Search Tree.
- Understand tree insertion and searching.
- Learn Preorder, Inorder, and Postorder traversals.
- Understand the importance of recursion in tree operations.
- Analyze the time and space complexity of tree operations.
- Understand how trees are used to represent hierarchical data.
