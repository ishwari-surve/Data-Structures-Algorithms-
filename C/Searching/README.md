## **Searching in C**

This folder contains programs that demonstrate the fundamental concepts of Searching in C, with a focus on locating elements efficiently in arrays.

## Topics Covered
### Searching Concept
-Searching an element
-Present / Absent condition
-Searching through array elements

### Linear Search
-Sequential comparison
-Start-to-end searching
-Best, average and worst cases
-Bi-Directional Search
-Searching from both ends
-Start and end pointers
-Simultaneous comparison

## Searching Analysis
-Best Case
-Average Case
-Worst Case
-Time Complexity
-Space Complexity

## Applications
-Searching records in arrays
-Finding a particular element
-Data lookup
-Database searching
-Information retrieval
-Checking whether an element exists
-Key Learning Points
-Understand the basic concept of searching.
-Learn how Linear Search works.
-Understand Bi-Directional Search.
-Compare searching techniques.
-Analyze time and space complexity.
-Determine whether an element is present in a collection.
