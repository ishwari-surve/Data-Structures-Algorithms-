#  Tree - in C

## Overview

This repository contains the **complete step-by-step implementation of the Tree Data Structure** using the **C Programming Language**. The programs are organized sequentially, beginning with the basic structure of a tree and progressing towards the implementation of various tree operations and traversals.

A **Tree** is a hierarchical, non-linear data structure that consists of **nodes** connected by **edges**. The topmost node is called the **Root**, and each node can have one or more child nodes. Trees are widely used to represent hierarchical relationships and enable efficient searching, insertion, and deletion operations.

---

#  What is a Tree?

## Definition

A **Tree** is a non-linear hierarchical data structure where:

- Each node stores data and links to its child nodes.
- The topmost node is called the **Root**.
- Every node (except the Root) has exactly one Parent.
- Nodes without children are called **Leaf Nodes**.
- There are no cycles in a tree.
- Every child subtree is itself a Tree.
