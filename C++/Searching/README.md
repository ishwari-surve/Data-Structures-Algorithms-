# **Searching in C++**

## **Description**

This folder contains C++ programs based on the **Searching** concept.

The programs demonstrate different searching techniques using arrays and object-oriented programming concepts. The programs are implemented step by step, starting from basic array operations and progressing towards a complete menu-driven searching application.

## **Concepts Covered**

* **Array**
* **Class and Object**
* **Parameterized Constructor**
* **Destructor**
* **Dynamic Memory Allocation**
* **Member Functions**
* **Boolean Functions**
* **Linear Search**
* **Bi-Directional Search**
* **Menu Driven Application**
* **Switch-Case**
* **Time and Space Complexity**

## **Searching Techniques**

### **1. Linear Search**

Linear Search checks each element of the array sequentially until the required element is found or the complete array is searched.

**Time Complexity:** `O(n)`

### **2. Bi-Directional Search**

Bi-Directional Search checks elements from both ends of the array simultaneously and moves towards the center.

**Time Complexity:** `O(n)`
